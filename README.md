# Expense Tracker CLI 


## Description

Expense Tracker is a command-line application build using Python.

It allows user to add, view, calculate and delete expenses. This expenses are permanently stored in a JSON file, so they remain available even after closing the application.


## Features

- Add Expenses
- View Expenses
- Calculate Total Expenses
- Delete Expenses
- Save Expenses using JSON
- Load Expenses automatically when the program starts
- Input Validation


## Technologies Used

- Python
- JSON
- datetime module
